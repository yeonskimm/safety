# 오늘의안전 (Today's Safety)

전담 안전관리자가 없는 **50인 미만 소규모 사업장**의 현장 작업자가, 설치 없이 브라우저만으로 작업 전 안전점검을 마치고 AI 상담까지 받을 수 있는 PWA입니다.

- 서비스: <https://yeonskimm.github.io/safety/>
- 현재 버전: **v95**
- 개발·운영: 대구지방고용노동청 광역산재예방감독과

---

## 1. 왜 만들었나

소규모 사업장은 안전관리자 선임 의무가 없어, 현장 작업자가 "오늘 이 작업에서 무엇을 확인해야 하는지"를 스스로 판단해야 합니다. 기존 안전점검표는 종이 기반이고 업종·작업 구분이 없어 현장에서 잘 쓰이지 않습니다.

이 앱은 **업종 → 작업 → 체크리스트**의 3단계만으로 그날 그 작업에 맞는 점검 항목을 제시하고, 결과를 이미지 보고서로 남깁니다.

---

## 2. 주요 기능

| 기능 | 설명 |
|---|---|
| 맞춤 체크리스트 | 업종·작업 선택 시 해당 작업의 점검 항목 자동 구성. 중대재해 직결 항목은 별도 표시 |
| 비정형 작업 LOTO | 수리·청소 등 비정형 작업에 전원 차단·잠금·표지 절차 안내 |
| AI 안전 리포트 | 점검 결과를 바탕으로 위험 진단 리포트 생성, 이미지 저장·공유 |
| AI 안전상담 | 산업안전보건법령 기반 질의응답. 실제 주입된 조문을 근거 칩으로 표시 |
| 한/영 이중언어 | 외국인 근로자를 위한 전체 화면 영문 전환 |
| 체감온도·폭염 단계 | 기상청 공식 산식 기반 체감온도 계산 및 단계별 조치 안내 |
| 점검 이력 | 최근 200건 로컬 보관, 월별 조회 |
| 오프라인 동작 | Service Worker 캐시로 네트워크 없이도 체크리스트 이용 가능 |

## 3. 아키텍처

```
[브라우저 PWA]                  [Cloudflare Worker]           [외부 API]
 index.html          ─ HTTPS ─▶  safety-ai-proxy  ────────▶  Groq (gpt-oss-120b)
 service-worker.js                · 법령 RAG 검색              └ 실패 시 Gemini 폴백
 manifest.json                    · 프롬프트 구성             Open-Meteo / wttr.in
 (GitHub Pages)                   · 답변 조문 검증            BigDataCloud
                                  · 이용통계 (KV)
        law_kb.json ────────────▶
        (법령 1,227조문)
```

- **API 키는 앱에 존재하지 않습니다.** 모든 외부 호출은 Worker를 경유합니다.
- Worker는 `https://yeonskimm.github.io` 출처만 허용합니다(CORS 화이트리스트).
- 관리자 인증은 서버에서 PIN을 검증하고 세션 토큰을 발급합니다(v94부터). 앱 코드에 PIN이 없습니다.

## 4. 법령 검색 (RAG)

AI가 법 조항을 지어내지 않도록 3단계로 방어합니다.

1. **검색** — 질문에서 키워드·동의어를 뽑아 `law_kb.json`에서 관련 조문을 항(項) 단위로 추출
2. **주입** — 추출된 조문 원문만 프롬프트에 넣고, 적용 요건·단서(`lawProvisos`)를 별도로 명시
3. **검증** — 생성된 답변에 주입하지 않은 조문번호가 있으면 표기를 제거하고 확인 안내를 붙임

화면의 `📖 법령 근거` 칩은 **AI가 쓴 문장이 아니라 검색엔진이 실제로 주입한 조문 목록**입니다.

### 법령 DB

| 법령 | 조문 수 |
|---|---|
| 산업안전보건법 | 184 |
| 산업안전보건법 시행령 | 124 |
| 산업안전보건법 시행규칙 | 250 |
| 산업안전보건기준에 관한 규칙 | 669 |
| **합계** | **1,227** (+ 별표 13종 350청크) |

출처: 국가법령정보센터. 파싱 오류가 확인된 조문은 `bad` 플래그로 검색에서 제외합니다.

> ⚠️ 이 앱의 안내는 참고용입니다. 법적 효력이 있는 해석은 국가법령정보센터(law.go.kr) 또는 관할 고용노동청에서 확인하십시오.

## 5. 파일 구조

```
index.html          앱 본체 (단일 파일 — HTML/CSS/JS 일체)
service-worker.js   오프라인 캐시 (Stale-While-Revalidate)
manifest.json       PWA 매니페스트
law_kb.json         법령 검색 DB
worker.js           Cloudflare Worker (AI 프록시 · RAG · 통계 · 관리자)
tools/              법령 DB 빌드 도구
  hwpx_extract.py   별표 HWPX -> 텍스트
  build_annex.py    별표 청크 생성
  build_kb.py       law_kb.json 빌드
  validate_kb.py    빌드 결과 검증
tests/
  run_all.sh        전체 검증 일괄 실행
  test_verify.js    답변 조문 검증 로직 테스트
```

별표를 추가할 때는 `hwpx_extract.py` → `build_annex.py` → `build_kb.py` → `validate_kb.py` 순으로 실행합니다.

## 6. 검증

모든 릴리스 전에 저장소 루트에서 실행합니다.

```bash
bash tests/run_all.sh    # 실패 시 종료코드 1
```

검사 항목:

- JS 문법 (`node --check`)
- HTML 태그 균형 (div / script / style / button)
- `APP_VERSION`(index.html) ↔ `CACHE_NAME`(service-worker.js) 버전 동기화
- 체크리스트 DB 중복 키
- 작업유형 한/영 매핑 4방향 정합성
- Playwright 렌더링 테스트

## 7. 개인정보 처리

- 점검 이력·설정은 **이용자 기기(localStorage)에만** 저장되며 서버로 전송되지 않습니다.
- 서버(KV)에 저장되는 것은 익명 이용통계와, 이용자가 직접 남긴 의견·연락처(180일 후 자동 삭제)뿐입니다.
- 관리자 화면의 연락처는 기본 마스킹 표시되며, 회신이 필요할 때만 탭하여 전체를 확인합니다.
- 위치 정보는 날씨 조회에만 사용하고 저장하지 않습니다.

---

## 8. 기술 스택

- 프론트엔드: 단일 HTML 파일 (빌드 도구·프레임워크 없음)
- 호스팅: GitHub Pages
- 백엔드: Cloudflare Workers + Workers KV
- AI: Groq `openai/gpt-oss-120b` (폴백: Google Gemini)
- 날씨: Open-Meteo (폴백: wttr.in) / 위치: BigDataCloud

프레임워크를 쓰지 않은 이유는 현장 단말의 네트워크가 불안정한 경우가 많아, **첫 로딩에 추가 요청이 발생하지 않는 구조**가 필요했기 때문입니다.

## 9. 최근 변경 (v95)

- 법 제40·51·63조 본문 복구 — 특히 **제63조(도급인의 안전조치 및 보건조치)**가 검색에서 빠져 있던 문제 해결
- AI 답변에 실제 주입된 근거 조문을 칩으로 노출
- 이용량 한도(429) 안내를 분당 혼잡/일일 소진으로 구분 — 1분이면 풀리는 상황에 "내일 다시 시도"로 안내하던 문제 해결
- AI 기능의 `Beta` 표기 제거 (면책 안내는 화면 내 고지로 유지)
- 관리자 화면 연락처 마스킹
- 작업유형 영문명 중복 해소 (`Equipment Repair & Cleaning (Chemical)`)
