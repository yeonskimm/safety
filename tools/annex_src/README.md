# annex_src — 별표 원본(HWPX) 보관 폴더

law.go.kr → 법령 검색 → 본문 우측 「별표/서식」 탭 → 해당 별표 → HWP/PDF 다운로드
받은 `.hwpx` 파일을 이 폴더에 넣고 `python3 tools/build_annex.py` 를 실행한다.
